Computer information.

153.(1)  This section applies if any of the material specified in an application for a production order consists of information contained in a computer.

Proceeds of Crime

2015-22 (2)  If the order is an order requiring a person to produce the material to an appropriate person for him to take away, it has effect as an order to produce the material in a form in which it can be taken away by him and in which it is visible and legible.

(3)  If the order is an order requiring a person to give an appropriate person access to the material, it has effect as an order to give him access to the material in a form in which it is visible and legible.
