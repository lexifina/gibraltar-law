REPORTING DUTIES

Reports on progress targets.

30.(1)  The Minister must lay before Parliament a report in respect of each year in the period 2020–2045 for which a progress target has been set (a “target year”).

(2)  The report must state whether the progress target for the target year has been met.

(3)  If the progress target has not been met, the report must explain why.

(4)  The report must also contain the information mentioned in section 31.

(5)  The report under this section must be laid before the Parliament no later than 31 October in the second year after the target year.
