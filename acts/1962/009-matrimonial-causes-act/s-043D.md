Consent orders for financial provision on property adjustment.

43D.(1) Notwithstanding anything in the preceding sections of this Part, on an application for a consent order for financial relief the court may, unless it has reason to think that there are other circumstances into which it ought to inquire, make an order in the terms agreed on the basis only of the prescribed information furnished with the application.

(2) Subsection (1) applies to an application for a consent order varying or discharging an order for financial relief as it applies to an application for an order for financial relief.

“consent order”, in relation to an application for an order, means an order in the terms applied for to which the respondent agrees;
