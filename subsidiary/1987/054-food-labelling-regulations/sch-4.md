Glazing agents Artificial sweeteners Preservatives Colours

Notes

1.  In the case of an additive which is added to or used in food to serve the function of an acid and whose specific name includes the word “acid”, it shall not be necessary to use the category name.

2.  It shall be sufficient, in the case of an additive which is identified by this category name, to use the category name alone.

3.  This category name shall be used only for an emulsifying salt, as defined in the Cheese Regulations 1987 which is added to or used in processed cheese (including cheese spread).
