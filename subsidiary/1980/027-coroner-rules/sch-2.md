SCHEDULE 2. Rule 4

Fees for Copies.

Item £ 1. For a copy of any deposition, report, notes of evidence or document put in evidence-

(a) if made xerographically, for each scheet

(i) not exceeding in size 22x33cms 0.10 (ii) of any larger dimension 0.20 (b) if typewritten, for each page or part of a page of the copy

0.50 (c) for a carbon copy of a typewritten copy bespoken, for each page or part of a page as typed

0.25 2. For certifying a copy to be a true copy of the original–

(a) if the copy is xerographic 0.50 (b) if the copy is typewritten, for each page 0.50
