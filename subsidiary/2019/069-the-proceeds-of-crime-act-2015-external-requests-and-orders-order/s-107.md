Financial threshold

107.(1) At any time when an order specifying an amount for the purposes of this article has effect, the Attorney General may not start proceedings for a recovery order unless it reasonably believes that the aggregate value of the recoverable property which it wishes to be subject to a recovery order is not less than the specified amount.
